# 🏫 Education CRM Portal

**Education CRM Portal** is a full-stack web application designed for educational institutes and training centers.  
It helps manage leads, admissions, batches, students, fees, and communications — all in one place.  
The system streamlines academic and operational management for institutes.

---

## 🚀 Features

- 🎯 **Lead & Enquiry Management** – Capture, track, and convert student leads.  
- 🧾 **Admission & Enrollment** – Manage new admissions and batch assignments.  
- 📚 **Course & Batch Management** – Define courses, schedule batches, and assign instructors.  
- 👨‍🎓 **Student Portal** – Students can log in to view schedules, progress, and payments.  
- 💰 **Fee & Payment Tracking** – Generate invoices, record payments, and send reminders.  
- 📊 **Dashboard & Reports** – Admin view of admissions, revenue, and student analytics.  
- ✉️ **Communication Module** – Send notifications via email or SMS.  
- 🔒 **Role-Based Access** – Different panels for Admin, Counselor, Instructor, and Student.

---

## 🧠 Tech Stack

**Backend:**  
- Java 17+  
- Spring Boot (Spring MVC, Spring Data JPA, Spring Security)  
- MySQL Database  

**Frontend:**  
- Thymeleaf  
- HTML, CSS, JavaScript  
- jQuery, AJAX  
- Bootstrap  

**Other Tools:**  
- Git & GitHub  
- Postman for API Testing  
- Maven for Build

## ⚙️ Installation & Setup

```bash
# Clone the repository
git clone https://github.com/yourusername/EducationCRMPortal.git

# Navigate to project folder
cd EducationCRMPortal

# Build and run the application
mvn spring-boot:run
```

Make sure MySQL is running and database credentials are configured in `application.properties`.
